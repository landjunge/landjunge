# netzwerkpunkt

I build tools for working with AI — local-first, with context, control and responsibility.

The short version: a house with five rooms.

- **ThreadDesk** — the notebook. Stores decisions and open context. Executes nothing.
- **TollGate** — the door. Checks every agent action before it runs: who, what, allowed? Budget, loops, freeze, audit.
- **4AllPass** — the safe. Local password manager, zero-knowledge. No AI touches the keys without your word.
- **KiraBridge** — the phone in the hallway. Connects the tools. [Public Snapshot](https://github.com/landjunge/KiraBridge-public)
- **Agent Authority Lab** — the observer. Never intervenes. Only reports.

Each room: one job. Nobody meddles.

Status: ~70% done, honestly unfinished, in daily use.
