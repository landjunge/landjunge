# netzwerkpunkt

Ich baue Werkzeuge für die Arbeit mit KI — lokal-first, mit Kontext, Kontrolle und Verantwortung.

Die Kurzversion: ein Haus mit fünf Zimmern.

- **ThreadDesk** — das Notizbuch. Speichert Entscheidungen und offenen Kontext. Führt nichts aus.
- **TollGate** — die Tür. Prüft vor jeder Agenten-Aktion: Wer, was, erlaubt? Budget, Loops, Freeze, Audit.
- **4AllPass** — der Safe. Lokaler Passwort-Manager, Zero-Knowledge. Keine KI an die Schlüssel ohne dein Wort.
- **KiraBridge** — das Telefon im Flur. Verbindet die Werkzeuge. [Public Snapshot](https://github.com/landjunge/KiraBridge-public)
- **Agent Authority Lab** — der Beobachter. Greift nie ein, meldet nur.

Jedes Zimmer: eine Aufgabe. Keiner mischt sich ein.

Stand: ~70% fertig, ehrlich unfertig, täglich in Gebrauch.
